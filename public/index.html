SERVICIOS AWS DEL PROYECTO

La aplicación corre localmente. Esta es la arquitectura preparada para desplegarla, no una nube que ya esté activa.

DESPLIEGUE PENDIENTE
ENTREGA PÚBLICA

CloudFront

Serviría el sitio por HTTPS y almacenaría en caché los archivos estáticos.

ORIGEN PRIVADO

Amazon S3

Guardaría la web con acceso público bloqueado. CloudFront entra mediante Origin Access Control.

API OPCIONAL

AWS Lambda

Puede ejecutar el mismo simulador mediante Function URL. El demo principal no depende de la función.

SOLO CON LAMBDA

CloudWatch Logs

Recibiría los registros de ejecución de la función. La simulación del navegador no requiere logs de AWS.

CONTROL DE COSTOS

AWS Budgets

El script puede crear el tope mensual de USD 10 y alertas por correo al 50 % real y 80 % previsto.

DESPLIEGUE

CloudFormation + SAM

SAM define y despliega la pila de CloudFormation. El presupuesto se solicita por separado desde el script.

No usamos base de datos. El presupuesto, las alertas y la URL pública todavía requieren despliegue y una cuenta AWS del equipo.
